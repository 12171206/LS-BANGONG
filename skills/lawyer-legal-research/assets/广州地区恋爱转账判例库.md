## 一、恋爱期间转账性质认定（赠与 vs 借款）

### 案例1：白云区法院——小伟诉小兰案（2022）
- 最后核实：待核 / 来源层级：官方（广州市白云区人民法院官网）
- **来源**：广州市白云区人民法院官网 byfy.by.gov.cn
- **核心事实**：恋爱期间男方400笔转账，其中520/1314特殊数字200余笔，备注"爱你宝贝""永远对宝贝好"70余笔；分手时男方列手写账单20余万要求还款；女方微信对账承认用了男方支付宝/银行卡94,892元。
- **判决结果**：只支持 **94,892元**（女方自认消费部分，认定为借款）；其余特殊数字款项认定为一般赠与，不予返还。
- **裁判要旨**：
  1. 恋人间转账无一笔备注"借款"，无债权凭证，不符合出借常理
  2. 特殊数字（520/1314）+ 备注爱意文字 → 推知为表达爱意的一般赠与
  3. 但女方事后微信对账自认使用金额并同意还款 → 该部分转化为借款
- **对本案参考**：🔴 特殊数字部分不要硬诉；🟢 女方事后自认的部分可以固定为借款证据

### 案例2：荔湾区法院一审 → 广州中院二审维持——小梁诉小付案
- 最后核实：待核 / 来源层级：官方（广州中院官网；南方都市报、湛江日报转载仅作辅助）
- **来源**：广州中院官网 gzcourt.gov.cn（南方都市报/湛江日报转载）
- **核心事实**：恋爱期间男方转账202万，其中一笔52万；女方辩称是"520我爱你"特殊含义赠与；女方曾转账50万给男方。
- **判决结果**：认定为民间借贷，判还 **152万本息**。广州中院二审维持原判。
- **裁判要旨**：
  1. 微信聊天记录证明男方无赠与/投资意思表示
  2. 女方收款后转账50万给男方 → 印证还款性质
  3. **52万金额与"520"含义相差过大**，不构成特殊数字赠与
  4. 大额、时间间隔近的转账，不符合亲密关系赠与特征
- **对本案参考**：🟢 整数大额转账（尤其几万以上）不要被"520"话术唬住，只要金额与特殊数字谐音差距大，且有借款合意证据，能认定借款

### 案例3：黄埔区法院一审 → 广州中院二审维持——小朱诉小龙案
- 最后核实：待核 / 来源层级：官方（广州中院官网）
- **来源**：广州中院官网 gzcourt.gov.cn
- **核心事实**：恋爱5年，双方频繁互相转账；女方曾写5万借条；分手后男方持借条起诉。
- **判决结果**：**驳回全部诉请**。广州中院二审维持。
- **裁判要旨**：
  1. 借条未载明款项交付时间、方式
  2. 借条出具前男方所有转账均未备注借款，无具体转账能与5万借款对应
  3. 恋爱期间双方频繁互转、数额未超日常生活所需 → 更像情侣间经济支持，非借贷
  4. 女方转给男方的数额甚至多于男方转给女方
- **对本案参考**：🔴 光有借条不够，必须有对应的转账凭证+借款合意聊天记录；双方频繁互转的，法院倾向认定为情侣经济混同

## 二、同居期间房产/大额财产分割

### 案例4：番禺区法院一审（2013）穗番法民三初字第425号 → 广州中院二审——董某诉丁某案
- 最后核实：待核 / 来源层级：官方（广州中院官网）
- **来源**：广州中院官网 gzcourt.gov.cn
- **核心事实**：恋爱同居期间共同购房，登记双方共同共有；分手后分割。
- **判决结果**：按共同共有分割，扣除剩余贷款后竞价50.5万，男方拿房，折价补偿女方89,687.75元。
- **裁判要旨**：同居期间为结婚目的购房登记双方名下 → 认定共同共有；分手时按出资+共同共有原则分割，不是谁出资就归谁。
- **对本案参考**：🟡 同居购房不是"谁出钱归谁"，登记了名字就有份额

## 三、证据规则（微信聊天记录/电子证据）

### 案例5：番禺区法院——常女士诉钟先生案
- 最后核实：待核 / 来源层级：官方（广州中院官网）
- **来源**：广州中院官网 gzcourt.gov.cn
- **核心事实**：男方伪造微信聊天记录赖掉6000元交通事故赔偿借款。
- **判决结果**：男方伪造证据，番禺法院罚款 **2万元**；男方承认该6000元为借款并还款，女方撤诉。
- **裁判要旨**：
  1. 法院要求双方当庭出示手机原始聊天记录
  2. 无法提供原始载体的一方，其提交的截图不被采信
  3. 伪造重要证据、严重扰乱司法秩序 → 罚款
- **对本案参考**：🟢 你方证据必须保留原始手机（不删好友、不删聊天）；🟢 对方截图证据可以要求出示原始载体，对方拿不出就可以质证不认可

## 四、附条件赠与（彩礼/购房款/结婚为目的）

### 案例6：揭阳榕城法院一审 → 揭阳中院二审——梁先生诉陈小姐案（2025）
- 最后核实：待核 / 来源层级：媒体转载（光明网转广州日报，仅作方向参考）
- **来源**：光明网转广州日报
- **核心事实**：恋爱期间男方出资86,790元以女方名义购房；分手后男方要求返还购房款及恋爱期间财物共12万。
- **判决结果**：支持返还购房款 **86,790元**；驳回520/1314等特殊数字转账及其他小额赠与。
- **裁判要旨**：
  1. 购房款是以结婚为目的的附条件赠与 → 结婚目的不能实现，应予返还
  2. 特殊数字转账、日常小额花销 → 一般赠与，不返还
- **对本案参考**：🟢 大额、明显以结婚为目的的支出（购房、大额彩礼），分手可要回；🔴 日常小额、特殊数字 → 赠与不返还

## 五、办案要点速查（从以上判例提炼）

| 证据要点 | 怎么做 | 参考案例 |
|---|---|---|
| 特殊数字转账（520/1314/9999） | 不要硬诉，支持率极低 | 案例1、案例6 |
| 整数大额转账 | 收集借款合意聊天记录+转账凭证 | 案例2 |
| 只有借条没转账凭证 | 风险极高，可能败诉 | 案例3 |
| 微信聊天记录 | 保留原始手机，开庭出示；不要删好友 | 案例5 |
| 对方截图证据 | 要求出示原始载体，拿不出就质证不认可 | 案例5 |
| 事后自认 | 对方微信承认"我会还你""我用了你多少"要固定成证据 | 案例1 |
| 同居购房 | 登记名字=有份额，按共同共有分割 | 案例4 |
| 结婚目的大额支出 | 可主张附条件赠与要求返还 | 案例6 |
