# 证据原件交接单

> 当事人交来的**原件/原始载体**，收了什么、几页、什么时候还，必须有签字留痕。
> 原件丢失或损毁是律所高额赔偿的高发点，也是客户最容易反咬一口的地方。
> 用法：每次收/还都填一张；扫描件附在本单后；结案归档时与案卷一起装订。

## 三、当面确认事项（逐条向当事人说明并打勾）

- [ ] 电子数据须保留**原始载体**，开庭可能要求当庭出示；交付期间不要删除聊天记录、不要更换手机
- [ ] 原件如已提交法院，法院一般不退还，我方留存复印件/照片并与本单对应
- [ ] 若当事人需要提前取回原件，须提前 3 个工作日书面告知，并重新签一张交接单
- [ ] 律师仅对**本单列明**的材料负责；未列明的材料视为未交付
- [ ] 证据真实性由当事人负责，律师不得、也不会指导伪造或变造证据

## 五、异常处理

| 情况 | 处理 |
|---|---|
| 原件在律师保管期间丢失/损毁 | 立即书面报告合伙人，启动所内赔偿与说明程序，不得隐瞒 |
| 当事人主张"交了但单上没有" | 以本单为唯一依据；无本单记录的不予认可，并要求当事人补充说明 |
| 电子数据载体需送鉴定 | 另行填写移交清单，注明密封状态并由双方在封口处签字 |
| 当事人坚持不留原件只给照片 | 在状态栏注明"仅提供照片/截图，未收取原件"，并提示举证风险 |
