# 案件工作台总设计

> 设计目标：一个案子从咨询到结案，所有材料、证据、程序产出物、时间节点都在一个"工作台"里联动，不是 5 个散工具各干各的。

---

## 一、工作台长什么样（一个案子 = 一个文件夹）

每个新案子进来，先建一个标准文件夹，所有东西都往里放：

```
案件-2026-XXX-张三诉李四民间借贷/
│
├── 00-案件档案/                    ← 合同、收费、授权
│   ├── 案件基本信息.md              ← 这个案子是谁、告谁、多少钱
│   ├── 委托代理合同.pdf
│   ├── 授权委托书.pdf
│   └── 收费凭证.pdf
│
├── 01-材料收集/                    ← 当事人给的、律师调的
│   ├── 当事人提供/
│   │   ├── 身份证复印件.jpg
│   │   ├── 转账记录/
│   │   ├── 聊天记录截图/
│   │   └── 其他材料/
│   ├── 律师调取/
│   │   ├── 银行流水（盖章版）.pdf
│   │   └── 工商登记信息.pdf
│   └── 材料收集清单.md             ← 收了什么、还缺什么
│
├── 02-证据整理/                    ← EV-01 程序的产出
│   ├── 证据目录.md                  ← 法院标准格式
│   ├── 证据三性审查表.md
│   ├── 证据链图谱.md
│   ├── 质证意见.md（针对对方证据）
│   └── 补证清单.md                  ← 还缺什么证据、怎么取
│
├── 03-法律研究/                    ← LR-01 程序的产出
│   ├── 法律研究报告.md
│   ├── 法条摘录.md
│   └── 类案判例/
│       ├── 广州中院-XXX案.md
│       └── 番禺法院-XXX案.md
│
├── 04-合同审查/（如涉及合同纠纷）    ← CR-01 程序的产出
│   ├── 原合同.pdf
│   ├── 审查报告.md
│   └── 修改版合同.docx
│
├── 05-诉讼策略/                    ← LA-01 程序的产出
│   ├── 策略分析报告.md
│   ├── 庭审提纲.md
│   └── 调解方案.md
│
├── 06-文书产出/                    ← LD-01 程序的产出
│   ├── 起诉状.docx
│   ├── 证据目录.docx
│   ├── 律师函.docx（如发过）
│   └── 代理词.docx
│
├── 07-程序记录/                    ↈ 时间线、沟通记录
│   ├── 立案受理通知书.pdf
│   ├── 开庭传票.pdf
│   ├── 庭审记录.md
│   └── 判决书.pdf
│
└── 08-结案归档/
    ├── 结案报告.md
    ├── 复盘记录.md
    └── 案卷装订目录.md
```

**命名规则**：
- 案件编号：`年份-序号-原告名诉被告名案由`，如 `2026-015-张三诉李四民间借贷`
- 证据命名：`证据XX-证据名称`，如 `证据01-2024年3月15日微信转账5万元.jpg`
- 文书命名：`文书类型-日期-版本`，如 `起诉状-20261031-v1.docx`

## 二、飞书多维表格案件看板（总控台）

所有案件在一张表里总览，每一行是一个案子：

| 字段 | 类型 | 说明 |
|---|---|---|
| 案件编号 | 文本 | 2026-015 |
| 案件名称 | 文本 | 张三诉李四民间借贷 |
| 客户姓名 | 文本 | 张三 |
| 对方当事人 | 文本 | 李四 |
| 案由 | 单选 | 民间借贷/离婚后财产/劳动争议/刑事辩护/医美纠纷/…… |
| 承办律师 | 人员 | 唐律师 |
| 当前阶段 | 单选 | 咨询中/已接案/取证中/已立案/待开庭/已判决/执行中/已结案 |
| 下一个动作 | 文本 | 补充银行流水 |
| 截止时间 | 日期 | 2026-11-15 |
| 争议金额 | 数字 | 90000 |
| 收费状态 | 单选 | 未收费/已收一半/已收全款/风险代理 |
| LR报告 | 附件链接 | 03-法律研究/法律研究报告.md |
| 证据目录 | 附件链接 | 02-证据整理/证据目录.md |
| 策略报告 | 附件链接 | 05-诉讼策略/策略分析报告.md |
| 起诉状 | 附件链接 | 06-文书产出/起诉状.docx |

**看板视图**：
- 按"当前阶段"分组 → 一眼看到哪些案子卡在哪个环节
- 按"截止时间"排序 → 下周该干什么
- 按"承办律师"分组 → 每个律师手上有多少案子

## 三、5 个程序怎么联动（关键！）

```
当事人来咨询
    │
    ▼
┌─────────────┐
│ LR-01 法律研究 │ ← 输入：当事人口述+初步材料
└─────────────┘
    │
    ├─ 结论：不建议接案 → 收咨询费，结束
    │
    └─ 结论：建议接案
            │
            ▼
     签委托合同 → 建案件工作台文件夹
            │
            ▼
┌─────────────┐
│ EV-01 证据处理 │ ← 输入：当事人提供的材料 + LR报告里的待证事实
└─────────────┘
    │
    ├─ 证据不足 → 出补证清单 → 发给当事人补材料
    │                │
    │                └─ 补完回来重新跑 EV-01
    │
    └─ 证据齐了
            │
            ▼
    涉及合同？──是──→ CR-01 合同审查
            │            │
            否           ▼
            │      审查报告放进 04-合同审查/
            │            │
            ▼◄───────────┘
┌─────────────┐
│ LA-01 诉讼策略 │ ← 输入：LR报告 + 证据目录 + 合同审查报告
└─────────────┘
    │
    ▼
┌─────────────┐
│ LD-01 文书起草 │ ← 输入：策略报告 + 证据目录
└─────────────┘
    │
    ▼
  立案 → 开庭 → 判决 → 执行 → 结案归档
```

**数据流转的关键**：
- LR-01 报告 → 自动告诉 EV-01"待证事实有哪些"，不用重复整理
- EV-01 证据目录 → 自动喂给 LD-01"起诉状里证据编号怎么对应"
- LA-01 策略报告 → 自动告诉 LD-01"诉讼请求怎么定"
- 所有产出物按路径存进案件文件夹，飞书看板挂链接

## 四、材料收集怎么做（按案由预置清单）

不同案由要收的材料不一样，提前预置好，律师照着清单要：

### 民间借贷类
- [ ] 原被告身份证复印件
- [ ] 转账凭证（银行盖章版流水/微信支付账单）
- [ ] 借条/欠条原件（如有）
- [ ] 催款聊天记录/通话录音
- [ ] 对方身份信息（身份证号/住址/电话）

### 婚恋经济/分手转账类
- [ ] 原被告身份证复印件
- [ ] 全部转账记录（标注哪些是520/1314特殊数字）
- [ ] 恋爱关系证据（合照/聊天记录/同居证明）
- [ ] 催款记录（最后一次催款时间）
- [ ] 对方虚构身份/理由的证据（如有）

### 劳动工伤类
- [ ] 劳动合同
- [ ] 工资银行流水（近12个月）
- [ ] 考勤记录/工牌/工作群聊天
- [ ] 解除/辞退通知
- [ ] 工伤医疗记录、诊断证明

### 医美维权类
- [ ] 服务合同、缴费凭证
- [ ] 术前术后对比照片/视频（带时间）
- [ ] 手术记录、病历
- [ ] 医院宣传广告/朋友圈截图
- [ ] 沟通聊天记录

### 刑事辩护类
- [ ] 拘留通知书/逮捕通知书
- [ ] 当事人陈述笔录
- [ ] 受害人身份信息
- [ ] 涉案金额流水
- [ ] 既往前科材料（如有）

## 五、证据整合怎么放（标准化）

1. **编号规则**：证据一、证据二……按待证事实分组编号
2. **命名规则**：`证据XX-日期-内容简述.扩展名`
   - 例：`证据01-20240315-微信转账5万元.jpg`
3. **每份证据配一个说明**：
   ```
   证据一：2024年3月15日微信转账记录
   来源：原告手机微信导出
   证明内容：原告于2024年3月15日向被告转账50000元
   页码：1页
   ```
4. **证据链图谱**：在 `证据链图谱.md` 里画清楚
   ```
   待证事实：借款合意成立
   ├── 证据一：微信聊天记录（被告说"这钱算我借你的"）
   └── 证据二：通话录音（被告承认欠款）
   ```

## 六、案件生命周期 Checklist

每个阶段做完打勾：

```
□ 咨询阶段
  □ LR-01 法律研究报告完成
  □ 风险评估完成
  □ 接案/不接案决定

□ 接案阶段
  □ 委托合同签了
  □ 收费到位（或约定付费方式）
  □ 案件工作台文件夹建了
  □ 飞书看板录入

□ 取证阶段
  □ 材料收集清单逐项打勾
  □ EV-01 证据目录完成
  □ 补证清单发给当事人
  □ 证据链闭环无断点

□ 策略阶段
  □ CR-01 合同审查（如涉及）
  □ LA-01 策略报告完成
  □ 庭审提纲完成
  □ 调解底线跟客户确认

□ 立案阶段
  □ LD-01 起诉状完成
  □ 证据目录打印
  □ 立案材料递交
  □ 受理通知书拿到

□ 庭审阶段
  □ 质证意见准备
  □ 庭审提纲熟悉
  □ 开庭穿正装、带证据原件

□ 判决阶段
  □ 判决书收到
  □ 是否上诉评估
  □ 跟客户沟通结果

□ 结案归档
  □ 结案报告写了
  □ 复盘记录写了
  □ 案卷装订
  □ 飞书看板标记"已结案"
```

## 七、和之前 5 个 SKILL 的关系

之前做的 5 个 SKILL（LR-01/EV-01/CR-01/LA-01/LD-01）是**单个程序的操作手册**；
现在这个案件工作台是**把 5 个程序串起来的操作系统**。

用法：
1. 新案子进来 → 先建工作台文件夹（照本设计文档第一部分）
2. 每个阶段启动对应程序 → 把那个 SKILL.md 喂给 AI
3. AI 产出的东西按路径放进对应文件夹
4. 飞书看板挂链接，一眼看到进度
