# 案件生命周期 Checklist

> 每个阶段做完打勾，一眼看到案子卡在哪。

## 咨询阶段
- [ ] LR-01 法律研究报告完成
- [ ] 风险评估完成
- [ ] 接案/不接案决定
- [ ] 收费方案跟客户谈妥

## 接案阶段
- [ ] 委托代理合同签了
- [ ] 收费到位（或约定付费方式）
- [ ] 案件工作台文件夹建了
- [ ] 飞书看板录入
- [ ] 授权委托书签了

## 取证阶段
- [ ] 材料收集清单逐项打勾
- [ ] EV-01 证据目录完成
- [ ] 补证清单发给当事人
- [ ] 补证材料收齐
- [ ] 证据链闭环无断点
- [ ] 电子证据原始载体确认保留

## 策略阶段
- [ ] CR-01 合同审查完成（如涉及）
- [ ] LA-01 策略报告完成
- [ ] 庭审提纲完成
- [ ] 调解底线跟客户确认
- [ ] 胜诉概率跟客户如实沟通

## 立案阶段
- [ ] LD-01 起诉状完成
- [ ] 证据目录打印
- [ ] 立案材料递交
- [ ] 受理通知书拿到
- [ ] 诉讼费缴纳

## 庭前准备
- [ ] 对方证据收到
- [ ] 质证意见准备
- [ ] 庭审提纲熟悉
- [ ] 证据原件整理好（开庭要带）
- [ ] 开庭传票收到

## 庭审阶段
- [ ] 按时到庭
- [ ] 举证质证完成
- [ ] 最后陈述完成
- [ ] 庭审笔录核对签字

## 判决阶段
- [ ] 判决书收到
- [ ] 是否上诉评估
- [ ] 跟客户沟通结果
- [ ] 上诉期内决定是否上诉

## 执行阶段（如需要）
- [ ] 申请执行书准备
- [ ] 对方财产线索调查
- [ ] 执行立案

## 结案归档
- [ ] 结案报告写了
- [ ] 客户回访做了
- [ ] 复盘记录写了（这个案子有什么经验教训）
- [ ] 案卷装订
- [ ] 飞书看板标记"已结案"
