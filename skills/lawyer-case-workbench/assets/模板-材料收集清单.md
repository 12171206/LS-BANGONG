# 材料收集清单

> 按案由勾选，收齐一项打勾，缺的标红跟进。

## 通用材料（所有案子都要）
- [ ] 原告身份证复印件
- [ ] 被告身份信息（身份证号/住址/电话）
- [ ] 委托代理合同
- [ ] 授权委托书
- [ ] 收费凭证

## 按案由补充

### 民间借贷
- [ ] 转账凭证（银行盖章版流水 / 微信支付盖章账单）
- [ ] 借条/欠条原件
- [ ] 催款聊天记录
- [ ] 催款通话录音
- [ ] 最后一次催款时间确认

### 婚恋经济/分手转账
- [ ] 全部转账记录（标注特殊数字：520/1314/9999）
- [ ] 恋爱关系证据（聊天记录/合照/同居证明）
- [ ] 对方虚构身份/理由的证据
- [ ] 共同支出记录（房租/生活费）
- [ ] 分手催款记录

### 劳动争议/工伤
- [ ] 劳动合同
- [ ] 工资银行流水（近12个月）
- [ ] 考勤记录
- [ ] 工牌/工作证/工作群聊天
- [ ] 解除/辞退通知
- [ ] 工伤医疗记录、诊断证明
- [ ] 证人联系方式（同事）

### 医美维权
- [ ] 服务合同
- [ ] 缴费凭证
- [ ] 术前术后对比照片/视频（带时间）
- [ ] 手术记录、病历
- [ ] 医院宣传广告/朋友圈截图
- [ ] 术前沟通聊天记录
- [ ] 后续修复治疗费用凭证

### 刑事辩护
- [ ] 拘留通知书/逮捕通知书
- [ ] 当事人陈述笔录
- [ ] 受害人身份信息
- [ ] 涉案金额流水
- [ ] 既往前科材料（如有）
- [ ] 退赔/谅解材料（如已赔偿）

### 合同纠纷
- [ ] 合同原件
- [ ] 履行证据（交货单/验收单/付款记录）
- [ ] 对方违约证据
- [ ] 我方催告记录
