# 验收记录：两级输入门槛（P0 改造第 2 条）

**日期**：2026-10-31 ｜ **被验收技能**：`lawyer-legal-research`（LR-01）｜ **验收人**：Team Lead

## 验收目的

验证改造后"缺输入就撂挑子"是否变成"分级处理"：阻断级缺了停、可待补级缺了照样出稿并声明。

## 用例 A：缺阻断级（只给 3 项，缺"管辖地区"）

**输入**：研究问题 + 身份关系 + 金额（不给管辖）

**技能应做**：立即停止，逐项列出缺项，不得开工。

**实际行为**：

```
输入检查结果（两级门槛）
1 研究问题   阻断级 ✅ 已给
2 身份关系   阻断级 ✅ 已给
3 涉及金额   阻断级 ✅ 已给
4 管辖地区   阻断级 ❌ 缺 → 停止
→ 未产出报告。请补齐第 4 项后重新调用。
```

**判定**：✅ 通过。闸门仍然有效，没有因为改成两级而放水。

## 用例 B：阻断级齐、可待补级缺 4 项

**输入**：研究问题 + 身份关系 + 金额 + 管辖（4 项阻断级齐全），其余 4 项全缺。

**技能应做**：不停工，出稿，且第一屏固定写"本次产出基于 N 项待补信息"，缺项同步台账待补。

**实际行为**：产出了 [法律研究报告-LR-20261031-002.md](案件-2026-002-验收案（输入不全）/03-法律研究/法律研究报告-LR-20261031-002.md)，首屏第一行即：

> ⚠️ **本次产出基于 4 项待补信息**：①关键事实时间线（仅给 1 个节点）②研究深度 ③已有证据线索 ④对方可能抗辩方向。

报告其余部分：时间线把缺口节点单独标出、法条标"未联网核验"、未做判例检索如实写、风险三色、给出"不建议接"情形。

**判定**：✅ 通过。以前这种情况会被退回"请补齐 8 项"，现在直接给一份能拿去改的初稿 + 4 条补件清单。

## 与改造前的对比

| 场景 | 改造前 | 改造后 |
|---|---|---|
| 缺 1 项必填 | 立即停，无任何产出 | 只有缺阻断级才停 |
| 缺 4 项（非关键） | 立即停，无任何产出 | 出稿 + 首屏声明 + 补件清单 |
| 规则一致性 | §2 硬退 与 §6"可给初步结论"矛盾 | 统一走两级门槛，只一处规则 |
| 缺项是否被记住 | 靠人记 | 写进台账"待补"，补齐后改"已补齐" |

## 已知边界

两级分级本身依赖"缺了到底算哪级"的判断。同一份材料，评"初步咨询"和评"深度报告"的可容忍缺项不同——技能里已按保守方向定级（研究问题/身份/金额/管辖一律阻断），但具体到非常规案件类型时可能过严或过松，需在使用中按案由微调。
